# Теплота в формулах — физика, 8 класс

Статический тренажёр по приложенному фото конспекта: количество теплоты при нагревании и охлаждении, преобразование `Q = cm(t₂ − t₁)`, обозначения и единицы измерения. Числа в задачах придуманы только как учебные примеры применения этих формул. Пояснение о знаке `Q` при охлаждении выведено из формулы.

## Как запустить локально

Откройте `index.html` в браузере. Интернет, установка программ и сервер не нужны. На iPad распакуйте архив в «Файлы» и откройте `index.html` в Safari; если локальное открытие файлов на устройстве ограничено, воспользуйтесь GitHub Pages.

## Как разместить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое** этой папки (или ZIP после распаковки) в корень ветки `main`: `index.html`, `styles.css`, `script.js`, `questions.js`, `README.md`, папку `assets`.
3. Откройте **Settings → Pages → Deploy from a branch → main → /(root)** и сохраните настройку.

Все ссылки на файлы относительные, поэтому сайт работает и в репозитории вида `username.github.io/repository/`.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Разделы сайта и учебный конспект |
| `styles.css` | Оформление для планшета и телефона |
| `questions.js` | 44 задания с темами, навыками, ответами и пояснениями |
| `script.js` | Интерактивы, тренировка, опрос и локальная статистика |
| `assets/notes.jpg` | Уменьшенная копия приложенного фото конспекта |

Статистика хранится в `localStorage` конкретного браузера. Она не переносится между устройствами и удаляется кнопкой «Сбросить статистику» или при очистке данных сайта.
